## To koso vaprunk

1. Helper copy korat.
2. Claude, vo tumi adinch vaprotat to AI ugddat, ani novo chat suru korat.
3. Helper paste korat ani dhaddat.
4. Magir eka vellar giraykacho ekuch message paste korat (zaite message ekach pavtt copy kelear nanvam vo number-ui yetat), vo aichem kam sangat. Poilim nanvam ani number kaddat.

**He kednanch type korum nakat:** Giraykanchim nanvam vo phone number, ID number (Aadhaar, PAN, passport), bank, UPI vo card mahiti, password vo OTP, bholaikechi mahiti, vikri vo poixeanchi rokom (sogleank sangtat tem mol cholta).

Fukot vaprunk ani bodlunk (CC0). Hem draft korta; tumi sogllem svota check korun dhaddtat.
