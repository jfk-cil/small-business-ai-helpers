# Free hosting notes for storefront-page-builder

Plain steps for putting the page online without paying, and for pointing Instagram and WhatsApp at it. Services change their plans, limits and menus often. Before you rely on one, the owner checks that service's current terms. Nothing here is a promise about any service.

Never type a password, OTP, payment key or API key into the chat to get help with these steps. If a step asks for one, the owner types it into the service itself.

## Which option fits

| You have | Easiest free option | Use |
|---|---|---|
| Only a phone | A link-in-bio service, or Google Sites | The Mode B words (not the HTML file) |
| A website builder already (your portfolio site) | A new page on that site | The HTML file if it accepts custom HTML; otherwise the Mode B words |
| A helper with a laptop | A website builder that accepts custom HTML (GitHub Pages only if its terms fit; see section 4) | The HTML file as it is |

## 1. Google Sites
- Free with a Google account.
- It builds pages from its own blocks. It does not take a whole HTML file as a page. It has an embed option for HTML, but the code then shows inside a frame, which can look cramped on a phone.
- Best way: make one page, add a text box for the headline and about line, then for each offer a text box and a button (button label and link from Mode B). Add the FAQ as text.
- Publish, then copy the page's address. That is your [your page link].

## 2. A link-in-bio service
- Many offer a free plan with a short page of buttons. Most do not accept custom HTML.
- Add one button per offer, using the Mode B button labels and links, in the Offer map order. Put the headline and about line in the profile text.
- Some show how many people tapped each button. That count can go in the weekly check.
- Free plans often show the service's own branding and may limit features. Check current terms.

## 3. Your existing website builder
- If you already have a site (for example, your portfolio), add a new page called "Start here" or "Shop and workshops".
- If the builder has a "custom HTML", "code" or "embed" block, you can paste the HTML file there. Some builders only allow this on paid plans, and some put it in a frame: check current terms.
- If not, rebuild the page with the builder's own text and button blocks using the Mode B words.
- Make that page easy to reach from your home page.

## 4. GitHub Pages
- Free for public repositories on a free account. Everything in a public repository can be seen by anyone, so the file must hold nothing private (it shouldn't: only placeholders and your public links).
- Steps (best done by a helper on a laptop): create a free account, create a new public repository, upload the file named `index.html`, then in the repository's Settings open Pages, choose the main branch and save. The site address appears there after a short wait.
- To change the page later, edit `index.html` and save (commit) again.
- GitHub's rules say Pages is not meant for running an online business or a site mainly for selling. Read GitHub's current terms before you use it for a shop page, or pick another option.

## Point everything at the page

**Instagram bio:** Profile > Edit profile > Links > Add external link. Paste [your page link] and save. (Menus can differ by app version.)

**WhatsApp Business profile:** Android: ⋮ > Settings > Business tools > Business profile. iPhone: Settings > Business tools > Business profile. Add [your page link] as the website and save. (Menus can differ by phone.)

**Everywhere else:** the same one link on your Google Business Profile (see **google-profile-builder**), business cards, posters and email signature. One link everywhere.

**Quick links to one offer:** add `#` and the offer's id to the page link, for example [your page link]#workshops. Send that when someone asks about one offer.

## WhatsApp click-to-chat links
- Plain: `https://wa.me/[your number with country code, no +]`
- With a message ready to send: `https://wa.me/[your number with country code, no +]?text=Hi%2C%20I%20would%20like%20to%20book%20a%20workshop`
- The number is your WhatsApp Business number written with the country code first (India is 91), with no +, no spaces, no dashes and no leading zero. The owner types it in; this helper never fills in a real number.
- `%20` is a space and `%2C` is a comma. Tap the link on your own phone after publishing to check that the right chat opens with the message.

## Before you share the link
1. Every placeholder replaced (no dashed red outlines left on the page).
2. Every button tested on a phone, on mobile data, not only on Wi-Fi.
3. Prices, dates and policies are ones you are sure of, or say "ask me".
4. If your payment provider asks your site to show policies (refunds, terms, contact), what they must say is for a qualified person to check.
