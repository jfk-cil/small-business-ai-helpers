## To koso vaprunk

2. Claude, vo tumi adinch vaprotat to AI ugddat, ani novo chat suru korat.

**He kednanch type korum nakat:** Giraykanchim nanvam vo phone number, ID number (Aadhaar, PAN, passport), bank, UPI vo card mahiti, password vo OTP, bholaikechi mahiti.
