# How to match listings to a client's needs

The matching is done only on the rows the owner pasted. Never add a listing, and never fill a gap in a row with a guess.

## 1. Which rows to use
- Use rows with Status "Available" or no status.
- Put aside rows marked On hold, Sold, Rented or Withdrawn. Say so in one line ("Put aside: listings marked sold, rented, withdrawn or on hold"), without counting them.
- If a row has a name, phone number, flat, unit, plot, survey or house number, or building name, use it without those details and tell the owner in one line (kind only).

## 2. Check each requirement
For each row, check every requirement the client gave. Each one comes out as **meets**, **misses** or **check** (the row doesn't say).

| Requirement | Meets when | Notes |
|---|---|---|
| Buy or rent | Sale or rent column matches | Always a hard requirement. |
| Type | Same type | Flat = apartment. 2BHK = 2 bedrooms. Independent house and villa are different unless the client says either is fine. |
| Area | Area is one of the client's areas | Never judge "nearby" areas on your own. A neighboring area is a "check" only if the client said "or nearby". |
| Budget | Price or rent is at or under the top of the client's range | Compare like with like: a month's rent with a monthly budget, a total price with a total budget. 1 crore = 100 lakh. If units differ (per day vs per week, sq m vs sq ft pricing) or the price is "on request" or blank, it's a check. |
| Bedrooms | Same number, or more if the client said "at least" | For land, bedrooms don't apply. |
| Move-in month or dates | Available from is on or before the client's month or start date | "Now" meets any month. Blank is a check. For rentals, add "confirm it's free for the whole period" under Check before sending. |
| Each must-have | Named in Key features | Not named is a check, never a meet. |
| Each deal-breaker | Not present in the row | Present means the listing "has" a deal-breaker. Not mentioned is a check only if it's something a row would normally say (floor, pets allowed); otherwise treat it as not present. |

Size: if the client gave a minimum size and the row uses a different unit, don't convert it in what you write. Mark it as a check.

## 3. Sort into groups
- **Fits everything:** meets every requirement. A check on a fact the client didn't ask about doesn't matter here.
- **Close: one thing missing or unknown:** exactly one requirement is a miss ("Misses:"), a deal-breaker ("Has:") or a check ("Check:").
- Everything else is left out of the shortlist.

Show up to 5 listings in total, Fits first.

## 4. Order within each group
1. Fewer checks first.
2. Then listings that also have more of any extras the client said they'd like, if they named any.
3. Then the owner's row order.

Never show points, scores, stars or percentages. Never call a listing "the best" or "a great deal".

## 5. Reasons
- One line, made of the row's own words: area, bedrooms, "within budget", the must-haves it meets, available from.
- Never show a difference ("₹5,000 under budget"), a price per square foot, a distance, a travel time or a count.

## 6. When nothing fits
1. Write: "No listing fits everything."
2. Name the closest one or two from Close and what each misses or has.
3. Suggest the one requirement that, if relaxed, would bring in the most of them (for example, "If the client could look at Alto Betim as well, PV-07 and PV-12 would fit."). Never invent a listing or say you'll find more.
4. Give a short message the owner can send to ask the client:
```
Hi! I don't have an exact match right now.
Would you consider [the one requirement to relax]? Then I have options to share.
[your business name]
```

## 7. Things never to do
- Never say a listing is still available today, will go fast, will rise in value, will give a rental yield or return, or has clear title or approvals.
- Never mention the seller, landlord or another agent by name or number.
- Never rate or judge the client ("serious buyer", "low budget").
